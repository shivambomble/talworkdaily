# Taskify

Taskify is a robust Todo List application built with React and TypeScript, featuring intuitive drag-and-drop task management.

## Features

- **Add Tasks**: Quickly add new tasks to your list.
- **Drag & Drop**: Effortlessly move tasks between "Active" and "Completed" lists, or reorder them within the same list.
- **Edit Tasks**: Update the content of your tasks on the fly.
- **Complete/Delete**: Mark tasks as done or remove them permanently.
- **Responsive Design**: Clean and usable interface.

## Tech Stack

- **[React](https://react.dev/)** (v19)
- **[TypeScript](https://www.typescriptlang.org/)**
- **[react-beautiful-dnd](https://github.com/atlassian/react-beautiful-dnd)** - For smooth drag-and-drop interactions.
- **[react-icons](https://react-icons.github.io/react-icons/)** - For UI icons.

## Getting Started

Reference the scripts below to run the project locally.

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Running the App

Start the development server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Scripts

- `npm start`: Runs the app in development mode.
- `npm run build`: Builds the app for production.
- `npm test`: Launches the test runner.
